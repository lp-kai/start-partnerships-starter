# Wenn eine Antwort kommt

| Typ | Erkennen | Tun |
|---|---|---|
| Out-of-Office | Autoreply, Rückkehrdatum | Nichts. Wiedervorlage auf Rückkehr +2 Tage. Kein Deal. |
| Bounce | Mailer-Daemon | Adresse verifizieren (Lusha, Website), erneut; nie dieselbe Adresse zweimal |
| Interesse / Call-Angebot | Terminvorschlag, Rückfrage | Innerhalb 24h antworten, 2–3 Slots, Deal im CRM (Qualification) |
| Weiterleitung | „Ich leite an X weiter" | Kurz bedanken, X als Contact anlegen (nach Go), Wiedervorlage 7 Tage |
| Nein | klare Absage | Bedanken, Tür offen lassen, Deal Closed Lost mit Grund |
| Preisfrage | „Was kostet…" | Nicht per Mail beziffern: Call anbieten, Preise nur im Gespräch |

**Ton spiegeln:** Du/Sie und Sprache des Gegenübers übernehmen. Kurz bleiben.
**Nach dem Call:** Transkript (Notion/Granola) → KI schreibt Zusammenfassung + Action Items in den CRM-Stream → Follow-up mit ihren Worten, Custom-Deck wenn sinnvoll.
